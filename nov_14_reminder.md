## The teach-me prompt

The base is the Workflow.txt prompt (the "how I want you to work with me" doc). The teach-me version is that same prompt with a set of teaching rules layered on top — the workflow prompt in a different mode, not a separate unrelated document.

The open question from that day: whether the result should be an edit to Workflow.txt itself, or a new combined prompt file that includes it. It was asked and never answered.

The teaching rules as written on 2026-11-14:

> When explaining something to me, follow these rules:
>
> - Don't spam me with text. Keep responses short.
> - Explain only one thing at a time.
> - If you have more to say, stop and ask me if I want you to continue.
> - Start with a general, plain-language explanation. No dense details.
> - If something is too dense, I'll tell you, and you break it into separate explanations and we do them one at a time.
> - Avoid technical terms. I understand concepts fine, but jargon is dense and hard to parse. Only use a technical term when there's no plain-language way to say it (e.g. "a type" in Rust is necessary to call it a type).
> - Wait for me to process before moving on.

The plan at the time was to build the teach-me prompt by doing — use it in practice, notice what worked, then write the prompt from that. That didn't happen in the 2026-11-14 session; the session went to the leptos_starter workspace and then to zakken_server instead.
