# new page popup

Idea for what happens when you create a new page.

A popup appears. The background dims slightly - a semi-transparent
dark layer that hides the background a little.

In the middle of the screen, a box with the title, auto-selected.
Above it, in bigger text, the title as it's being typed. The text
is styled fancy in a modern way, maybe a glass effect. Each letter
shakes a little as it's inserted into the field, so the title above
feels alive.

Under the field, instruction text like "press enter to confirm" or
"press escape to cancel".

Press enter confirms. Escape (or whatever) cancels.
